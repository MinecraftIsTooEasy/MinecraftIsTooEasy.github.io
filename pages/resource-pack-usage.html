资源包安装方法

未安装 Better Game Setting

  1. 确认系统已显示文件扩展名，避免把文件误命名为 .zip.zip。
  2. 下载所需资源包。
  3. 将资源包重命名为 MITE Resource Pack 1.6.4.zip。
  4. 把 ZIP 放入 MITE 游戏目录的 .minecraft/resourcepacks/ 文件夹。
  5. 启动 MITE；能够正常进入游戏即表示安装成功。

已安装 Better Game Setting

  1. 把下载的 ZIP 直接放入 .minecraft/resourcepacks/ 文件夹，无需重命名。
  2. 启动游戏，在“游戏设置 → 资源包”中选择刚放入的资源包。
