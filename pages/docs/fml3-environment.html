IDEA 设置篇

  1. 下载 IntelliJ IDEA，社区版已经足够，不必购买专业版。
  2. 进入 IDEA 的设置和插件市场，下载 Minecraft Development Kit；如有需要，还可以下载汉化插件。
  3. 开发所需的部分依赖需要从国外下载，因此可能需要配置网络代理。
  4. 如果你已经掌握代理配置，可以跳过这一部分。
  5. 按下 Win+I，进入“网络和 Internet → 代理”，查看并记录地址与端口。
  6. 进入 IDEA 的代理设置，选择手动代理并填入上一步的地址与端口。

文件准备篇

  1. 下载并安装 Java 17，配置环境变量并记住安装路径。
  2. 准备 MITE 资源包，稍后运行客户端时使用。

项目构建篇

  1. 下载 模组开发模板 或其他 FML3 项目。
  2. 用 IDEA 打开其中的 build.gradle 文件，这是项目的构建脚本。
  3. 打开后项目会自动开始构建，请等待构建完成。
  4. 如果构建失败，可依次检查：
    • 项目 SDK 和语言级别是否设为 Java 17。
    • 报错指定的位置是否缺少 MITE.jar。
    • 项目依赖的 ManyLib 等前置是否已经准备好。
  5. 可以点击 IDEA Gradle 面板中的刷新按钮重新构建项目。

项目运行篇

  1. 在 IDEA 右侧栏找到 Gradle，项目任务都在其中。
  2. Tasks → build 中的 jar 用于生成模组，sourcesJar 用于生成源码包。
  3. Tasks → fml 中的 runClient 和 runServer 分别用于运行客户端和服务端。
  4. 如果客户端提示缺少资源包，请把准备好的资源包放入项目的 run 文件夹。
  5. genSources 可以生成 Minecraft 源码，执行前应关闭已打开的源码标签页。

项目编写篇

  1. 需要在开发和运行时加载的依赖使用 implementation。
  2. 只用于编译、不希望在运行时加载的依赖使用 compileOnly。
  3. 引入对应的 sources 文件后，可以在 IDEA 中查看源码和查找用法。
  4. 访问加宽需要在构建脚本和 fml.mod.json 中同时指定。
  5. FML3 中通常使用 Mixin 修改 Minecraft 代码来实现功能。

注意事项

本教程适用于较新的 FML 开发环境。部分旧项目仍使用旧环境，需要按照项目说明调整构建脚本。
