# 本地运行该网站

## 网站链接

1. 网站正式地址: https://minecraftistooeasy.github.io/index.html
2. 网站源码: https://github.com/ysesiq/minecraftistooeasy.github.io


## 操作步骤

0. 下载vscode; 学会在vscode使用终端; 知道如何向ai提问; 知道如何学习html, js
1. 通过fork等方式把网站源码下载到本地
2. 从ruby官网安装ruby
3. 终端内通过gem install bunder下载bundler
4. bundle install下载网站依赖
5. bundle exec jekyll serve启动服务器
6. 打开网址http://localhost:4000即可预览
7. 终端内ctrl+c关闭网站

## 向网站源码做贡献

1. 知道git工作流程
2. fork并提交pr或找xy申请项目权限并直接修改
