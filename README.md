# Modded MITE 网站

这是一个普通的静态网站，只使用 HTML、CSS 和 JavaScript，不需要安装 Node.js，也不需要运行命令。

## 最简单的打开方式

已经有项目文件时，直接双击根目录的 `index.html`。

从 GitHub 下载时只需两步：

1. 下载 ZIP 并解压。
2. 双击解压目录中的 `index.html`。

## 修改网站

- `index.html`：首页。
- `pages/`：资源、教程、开发文档和关于页面。
- `styles.css`：网站样式。
- `scripts/site.js`：页头、页脚和移动导航。
- `scripts/i18n.js`：中英文文字。
- `files/`：图片、图标和下载文件。

修改后重新打开或刷新 `index.html` 即可查看结果。
